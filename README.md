# Saloon X

Build the complete SalonX platform using the three provided reference screenshots as the EXACT visual design reference.



SalonX is an India-wide salon discovery, hairstyle discovery, AI hairstyle assistant and appointment booking marketplace.



The platform has three completely separate experiences:



1. Customer Website

2. Salon Owner Dashboard

3. Super Admin Dashboard



All three must use the SAME SalonX visual design system shown in the reference screenshots.



IMPORTANT:

Do not redesign the reference UI.

Do not simplify it.

Do not replace it with a generic SaaS template.

Keep the same overall layout, dark hero, purple accent, white cards, sidebar, typography, spacing, charts, icons, rounded corners, shadows and visual density.

Y. SUPER ADMIN ACCOUNT SECURITY



IMPORTANT:



Public users must NEVER be able to create a Super Admin account.



There are three roles:



CUSTOMER

SALON_ADMIN

SUPER_ADMIN



Customer:

Normal registration.



Salon Admin:

Can register salon account.



Super Admin:

Created securely by existing authorized Super Admin / initial secure setup.



Use strict role-based access control.



Salon Admin can only access their own salon data.



Customer can only access their own account and bookings.



Super Admin can access platform-level data.



Never rely only on frontend role checks.

Enforce permissions on backend/server/database as well.
